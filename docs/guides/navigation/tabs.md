# Tabs and Windows

OpenComic can keep multiple locations and readings open at the same time by using tabs.

This is useful when you want to switch quickly between different comics, folders, or server locations without losing your place.

![Tabs in OpenComic](/img/docs/navigation/tabs.png)

----

## What you can do with tabs

- Open multiple comics or folders at the same time.
- Switch between active readings without closing the current one.
- Reorder tabs by dragging them.
- Open new windows by dragging a tab out of the current window.
- Move tabs between existing windows.

----

## Multiple windows

Tabs are not limited to a single window.

OpenComic also supports multiple windows, so you can separate different readings or browsing sessions when needed.

You can drag a tab out of the current window to open it in a new one, or move tabs between existing windows.

----

## Opening files in a new window

OpenComic can also open files from outside the app in a new window instead of reusing the current one.

This is useful when you open files from the system file manager and want to keep your current session untouched.

----

## Restore windows from a previous session

OpenComic can restore your tabs when it starts and keep a list of recently closed windows.

1. In **Settings > General > Startup behavior**, enable **Restore tabs from last session**.
2. In **Settings > General > Recents**, choose how many recent windows to keep.
3. To reopen a saved window later, use **File > Recent windows**.

Set the number of recent windows to `0` to stop keeping a list of closed windows. The startup restore option also controls whether OpenComic saves and restores the tabs from your previous session.
