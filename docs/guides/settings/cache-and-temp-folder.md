# Custom cache and temporary files folder

OpenComic can store its cache and temporary files under a folder you choose. This can be useful when the default system location does not have enough space or when you want these files on another drive.

## Choose a folder

1. Open **Settings > General** and scroll to **Storage**.
2. Enable **Use custom folder for cache and temporary files**.
3. Select **Change** and choose the folder to use.

OpenComic creates its `opencomic/cache` and `opencomic/tmp` folders inside the selected location. Existing cache and temporary files are copied to the new location when you change this setting.

Choose a location with enough free space for both cache and temporary files. You can turn the setting off to return to the default location.
